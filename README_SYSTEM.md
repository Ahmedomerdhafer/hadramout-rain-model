## 2) مصادر البيانات (الروابط والأنماط الحرفية)

### GFS الفيزيائي — AWS Open Data
```
https://noaa-gfs-bdp-pds.s3.amazonaws.com/gfs.{YYYYMMDD}/{CC}/atmos/gfs.t{CC}z.pgrb2.0p25.f{FFF}.idx
```
- الرسائل المستخدمة: `APCP`/`ACPCP` (surface) بأنماط الوصف `0-1 day acc` (f024) و`0-10 day acc` (f240) و`0-14 day acc` (f336) و`\d+-\d+ hour acc` (الخطوات).
- التنزيل الجزئي: قراءة `.idx` → موضع البايت `d=` → `Range: bytes=start-end` (~1MB لكل رسالة بدل مئات الميغابايت).
- **اكتمال الدورة**: ف240 (وف336 للبحر) — منتجات 24س يكفيها f024.
- ⚠️ فحص النشر: عدّ المفاتيح بـ`?list-type=2&prefix=…` — **رمز HTTP يعيد 200 حتى للنتائج الفارغة!**

### AI-GFS (GraphCast) — NOAA EAGLE
```
https://noaa-nws-graphcastgfs-pds.s3.amazonaws.com/aigfs.{YYYYMMDD}/{CC}/model/atmos/grib2/aigfs.t{CC}z.sfc.f{FFF}.grib2(.idx)
```
- AIGFS v1.0 تشغيلي منذ ديسمبر 2025 (خلافاً للنسخ التجريبية القديمة `graphcastgfs.t…`).
- يمتد حتى **f384**؛ المتغيرات: نفس GFS تقريباً على 13 مستوى + سطحي.
- ⚠️ **حقل ACPCP صوري** (ثابت ≈ −0.002 عالمياً — مُتحقَّق) → الحصة الحملية تُشتق من `f_ref` المرجعي.
- النشر أبطأ من GFS بساعتين تقريباً لكل دورة.

### الرصد الأرضي — IEM ASOS (مطار الريان OYRN)
```
https://mesonet.agron.iastate.edu/cgi-bin/request/asos.py?station=OYRN&data=p01i&sts=…T…Z&ets=…T…Z&tz=UTC&format=onlycomma&missing=M&trace=T
```
- `p01i` بالبوصات (×25.4 → ملم؛ T = أثر ≈ 0.13 ملم). التواريخ **يجب** أن تكون بتوقيت واعٍ `…T…Z`.
- أخطاء 503 عابرة → إعادة محاولة بتباعد.

### ثوابت جغرافية ومناخية
- الحدود الإدارية: `data/gadm41_YEM_2.json` (GADM v4.1 — مديريات اليمن ADM2).
- سواحل/حدود: Natural Earth 50m (عبر cartopy).
- مناخ v17-HR1: `gfs_cache/v17replay/scenario_20260912.npz` (μ17, α) + `scenario_conv_2026091306.npz` (mu17_conv, f_ref) — أصله UFS Replay (NOAA PSL).
- العينة المرجعية: `v16ref/` و`convref/` (24 دورة GFS، 23 أغسطس–12 سبتمبر 2026) + `ref24_sample.npz` (النوافذ 0–24س المقترنة).
- الخط العربي: **Amiri** (تاجوال يفتقد الأشكال المعزولة).

## 3) المنهجية العلمية

### 3.1 معايرة QDM (Cannon et al. 2015) — الوصفة المُتحقَّق منها
```python
cnt = (refs_sorted < x0[None]).sum(axis=0)            # n=24 مرجعية
q    = clip((cnt+0.5)/(n+1), 1/(n+1), n/(n+1))        # رتبة النقطة الحالية
p    = (arange(n)+0.5)/n
ref_q = interp(q على شبكة p من المراجع المرتبة)        # مكافئ المرجع
g    = gamma.ppf(q, a=0.48447, scale=mu/a)  حيث mu>0  # مناخ v17 (صفر حيث mu=0)
scen = clip(g + x0 - ref_q, 0, None)                  # إضافة الدلتا
```
- `α = 0.48447` (شكل غاما مجمّع)، `n_ref = 24`.
- الحملي: `conv = min(QDM(x0c), tot)` ثم `strat = tot − conv`.

### 3.2 سلسلة 10 أيام (GFS)
`x0t/x0c` من f240 التراكمي → QDM على مراجع `v16ref/convref` بمناخ `mu17/mu17c`.

### 3.3 سلسلة 24 ساعة (GFS)
```
r = clip(uniform_filter(Σt24 / Σref10, 3×3), 0, 1)     # نسبة القياس الزمني (~6.1%)
mu17_24  = mu17 × r        ;        mu17c_24 = mu17_24 × f_ref
scen_24  = QDM(x0t_24, t24_sorted, mu17_24, α)
```
(العينات `t24/c24` من `ref24_sample.npz`.)

### 3.4 خط AI-GFS
نفس السلسلتين تماماً مع استبدال `x0t` بتراكمات AIGFS، والحملي من الحصة المرجعية:
`conv = tot × f_ref` (لأن ACPCP صوري — موثّق في حاشية المنتجات).

### 3.5 لوحة بحر العرب (14 يوماً)
- النطاق: خط طول 44.5–77.5، عرض −5→26 (عدن → كيرالا).
- الخطوات: 6-ساعية حتى f180 ثم 12-ساعية حتى f336.
- اللوحات: (1) APCP 0–14 يوم من f336 (2) أقصى سرعة رياح 10م من U/V كل خطوة ×3.6 (3) الضغط الأدنى PRMSL/100.
- **كشف المسارات تلقائياً**: أدنى ضغط محلي (مرشّح أدنى 5×5) ≤1005.5 hPa فوق المحيط (قناع shapely `contains_xy` على LAND) → تتبّع بمدى وصول 4.5°/6س، نقطة واحدة لكل مسار في كل خطوة، إبقاء المسارات ≥4 نقاط (≥24س) وذروتها ≤1004.5.
- نقاط مرجعية: المكلا، حديبو، صلالة، عدن، كوتشي، مومباي (قيمها في CSV).
- تنويه مثبت: ليس تحذيراً رسمياً — المرجع RSMC نيودلهي؛ النموذج الذكي ينعّم الشدة.

## 10) دروس ومزالق تقنية (لا تكررها)

1. **S3 يعيد 200 للقوائم الفارغة** — العدّ بالمفاتيح حصراً.
2. **APCP التراكمي برسالتين** في نفس الملف (خطوة + كلي) — رشّح بنمط الوصف (`0-10 day acc` إلخ).
3. **ACPCP في AIGFS صوري** (ثابت صفري) — لا تبنِ عليه.
4. **تعديلات متوازية على نفس الملف تفقد تعديلاتها** — تسلسل + `assert count==1` + `ast.parse`.
5. **نسبة أبعاد كارتوبي تقصّ المحاور العريضة** — استخدم أشكالاً بنسبة البيانات (عمودية للخريطة المفردة).
6. **`ax.text` بتحويل جغرافي على GeoAxes غير موثوق** في مواضع معينة — ارسم نصوص الخريطة عبر `fig.text` بإحداثيات `transData` بعد `canvas.draw()` **وبلا انعكاس y**.
7. **الهالة الشفافة (alpha) تُخفي النص الصغير** — هالة صلبة.
8. **`get_window_extent` غير موثوق** للتحقق — استخدم ألواناً فريدة أو عكس transData.
9. **OCR العربي (tesseract) لا يقرأ Amiri** — للتحقق البصري استخدم مقاييس حبر/ألوان.
10. **IEM يتطلب تواريخ واعية `…T…Z`** ويعطي 503 عابرة.
11. **npz لا يخزن النافذة** — تُشتق من اسم الملف بـregex.
12. **رسائل eccodes عند الخروج** (`free(): invalid pointer`) غير مؤثرة على المخرجات.
13. **المراجع المخزنة بترتيب عرض تنازلي** — تُقلب `[::-1]` عند التحميل.
14. **JPEG مائل (تصوير هاتف)** يفسد استخراج الألوان — تحقق من عدة صفوف وتتبّع الشريط عمودياً.
